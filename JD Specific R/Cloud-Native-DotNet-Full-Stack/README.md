# Cloud-Native .NET Full-Stack Interview Questions

This folder contains a company-neutral question bank for an intermediate-to-senior full-stack engineering role focused on modern .NET and Azure architecture.

## How to use this bank

1. Start with the **Priority 1** sections: OAuth 2.0/OpenID Connect, Microsoft Entra ID, API Management/Application Gateway, CQRS/event sourcing, and Azure containers.
2. Continue with the supporting backend, distributed-systems, DevOps, frontend, testing, and leadership sections.
3. Write answers later using `Prompt.md`; this folder intentionally contains questions only.
