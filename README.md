# Inkdown Markdown Studio

A local-first HTML editor for creating clean, GitHub-ready Markdown files.

## Use it

Open `index.html` directly, or start a local server with `python3 -m http.server 8080` and visit `http://localhost:8080`.

Write or open a Markdown document, check the live preview, and choose **Save Markdown**. Chrome and Edge can save directly to a folder you select. Other browsers download the `.md` file so you can move it into this repository before committing.

Draft text stays in browser local storage. Article content is never uploaded by this application.

## Features

- Live GitHub-flavored Markdown preview
- Formatting toolbar and front-matter generator
- `.md` import and export
- Safe, consistent file names
- Word count, line count, and reading time
- Responsive write, preview, and split views
- `Ctrl+S` / `Cmd+S` save shortcut
